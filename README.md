# How to Install

1. Remove current config
    1. Fresh clean:
    - `rm -rf ~/.config/nvim`
    - `rm -rf ~/.local/share/nvim`
    - `rm -rf ~/.local/state/nvim`
    - `rm -rf ~/.cache/nvim`

    2. Backup Current config: `mv ~/.config/nvim ~/.config/nvim.backup`

2. Clone repo: `git clone https://github.com/Daniel-Frederick/nvim-config ~/.config/nvim`

3. lazy.nvim should manually install the plugins
